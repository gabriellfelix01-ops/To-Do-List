Sobre o projeto

O To-Do List é uma aplicação de gerenciamento de tarefas onde o usuário adiciona o que precisa fazer e acompanha, em tempo real, quantas tarefas ainda restam.

Construí este projeto para consolidar conceitos essenciais de front-end: estruturação semântica com HTML, estilização responsiva com CSS e interatividade com JavaScript puro (sem frameworks), manipulando o DOM de forma dinâmica.
